# Canonical Progen dialect facts grounded in TEXTBOOK.md and LINK_INDEX.md.

linguistic sign = ferdinand de saussure semiotic unit uniting acoustic sound-image signifier with mental concept signified. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 1.1

arbitrariness of the sign : saussurean principle that there is no natural or intrinsic link between phonetic signifier and concept signified. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 1.1

phoneme = smallest contrastive unit in a language phonological system capable of distinguishing one word meaning from another. // door https://www.internationalphoneticassociation.org/ // ref chapter 2.1

morpheme = smallest meaningful or grammatical morphological unit in a language that cannot be further divided. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 2.2

syntax = rules and hierarchical structures governing how words combine into phrases, clauses, and sentences. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 2.3

principle of compositionality : gottlob frege principle stating meaning of complex expression is determined by meanings of its syntactic parts and rules used to combine them. // door https://plato.stanford.edu/entries/compositionality/ // ref chapter 2.4

universal grammar = noam chomsky theoretical framework positing innate biological human cognitive capacity structuring syntax acquisition. // door https://plato.stanford.edu/entries/chomsky/ // ref chapter 3.1

poverty of the stimulus : argument that child linguistic competence cannot be acquired purely from degenerate environmental input without innate linguistic constraints. // door https://plato.stanford.edu/entries/chomsky/ // ref chapter 3.2

context free phrase structure grammar = formal grammar generating syntactic tree structures via recursive production rules mapping non-terminals to constituent phrases. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 3.3

typology of writing systems : classification into logographic word characters, syllabic mora graphs, alphabetic phoneme symbols, abjad consonants, and abugida alphasyllabaries. // door https://www.unicode.org/standard/standard.html // ref chapter 4.1

unicode standard = universal character encoding standard assigning unique numeric code points across U+0000 to U+10FFFF for all world scripts. // door https://www.unicode.org/standard/standard.html // ref chapter 5.1

utf 8 byte allocation : variable-width encoding allocating 1 byte for ASCII code points, 2 bytes for European scripts, 3 bytes for CJK, and 4 bytes for emoji. // door https://www.unicode.org/faq/utf_bom.html // ref chapter 5.2

gricean cooperative principle : four conversational maxims facilitating efficient communication - quantity of information, quality of truth, relation of relevance, manner of clarity. // door https://plato.stanford.edu/entries/implicature/ // ref chapter 6.1

grimm law : historical linguistic sound shift showing proto-indo-european voiceless stops shifted systematically to protogermanic voiceless fricatives. // door https://www.britannica.com/topic/Grimms-law // ref chapter 7.1

proto indo european language = reconstructed prehistoric ancestral language ancestor of romance, germanic, slavic, indo-iranian, celtic, and greek families. // door https://www.britannica.com/topic/Proto-Indo-European-language // ref chapter 7.2

sapir whorf hypothesis = principle of linguistic relativity positing structure of human language influences its speakers world perception and cognitive patterns. // door https://plato.stanford.edu/entries/linguistics/ // ref chapter 8.1

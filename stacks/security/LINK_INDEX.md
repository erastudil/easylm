# security — link index

Official **doors** into primary cryptographic, security engineering, network protocol, and vulnerability repositories.
When a standard cipher specification, RFC wire format, FIPS certification curve, or vulnerability advisory is load-bearing, fetch from the official authority and cite the URL.

| domain / body | scope & authority | official door |
|---|---|---|
| **NIST CSRC (Computer Security Resource Center)** | FIPS standards (140-3, 197 AES, 180-4 SHA, 203 ML-KEM), SP 800 series | https://csrc.nist.gov/ |
| **International Association for Cryptologic Research (IACR)** | Peer-reviewed cryptology papers, ePrint archive, Eurocrypt, Crypto | https://eprint.iacr.org/ |
| **IETF RFC Database** | Internet standards: RFC 8446 (TLS 1.3), RFC 7748 (Curve25519), RFC 7693 (BLAKE2) | https://www.ietf.org/standards/rfcs/ |
| **OWASP Foundation** | Open Web Application Security Project: Top 10, ASVS, Cheat Sheet Series | https://owasp.org/ |
| **Electronic Frontier Foundation (EFF)** | Surveillance Self-Defense, digital privacy, encryption advocacy | https://www.eff.org/ |
| **MITRE ATT&CK Framework** | Adversary tactics, techniques, and procedures (TTPs) matrix | https://attack.mitre.org/ |
| **National Vulnerability Database (NVD)** | Common Vulnerabilities and Exposures (CVE), CVSS scoring standard | https://nvd.nist.gov/ |
| **Bitcoin Developer Documentation** | Satoshi Nakamoto whitepaper, Bitcoin Improvement Proposals (BIPs) | https://bitcoin.org/en/developer-documentation |
| **Ethereum Foundation Research** | EVM specifications, Ethereum Improvement Proposals (EIPs), Yellow Paper | https://ethereum.org/en/developers/docs/ |
| **Signal Protocol Specifications** | Double Ratchet, X3DH, Sesame protocol engineering specs | https://signal.org/docs/ |
| **Tor Project Documentation** | Onion routing protocols, directory consensus, Tor specification | https://spec.torproject.org/ |
| **Phrack Magazine** | Historical systems security, offensive theory, low-level exploitation | https://phrack.org/ |

## Usage of Primary Doors
1. Identify whether the problem is cryptographic (IACR, NIST, IETF), software/application security (OWASP, MITRE), or distributed/crypto-economic (Bitcoin, Ethereum).
2. Fetch exact specification RFCs or FIPS documents rather than tutorial summaries.
3. For cipher primitives, verify against the NIST CSRC validation list or RFC test vectors.

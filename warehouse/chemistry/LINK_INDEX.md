## how to use a door

1. name the question in one sentence.
2. search with the query in the table.
3. open the **official** host (.gov, .edu, IUPAC, CIAAW, NIST), not a blog recap.
4. fetch the page if you will cite a mass, a K, a ΔH, or a hazard.
5. if two official pages disagree, say so. do not average them. a bottle SDS wins on *that bottle*.

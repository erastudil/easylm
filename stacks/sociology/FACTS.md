mechanical solidarity = social cohesion in traditional societies based on shared consensus, collective conscience, and low division of labor. // door https://plato.stanford.edu/entries/durkheim/ // ref chapter 1.2

organic solidarity = social cohesion in modern industrial societies based on functional interdependence arising from specialized division of labor. // door https://plato.stanford.edu/entries/durkheim/ // ref chapter 1.2

anomie = state of social deregulation and normlessness occurring when rapid societal change outpaces normative moral constraints. // door https://plato.stanford.edu/entries/durkheim/ // ref chapter 1.3

weberian rationalization = max weber concept describing historical transition from magical and traditional worldviews toward calculable bureaucratic efficiency. // door https://plato.stanford.edu/entries/weber/ // ref chapter 2.1

iron cage of bureaucracy : weber metaphor describing trapping of individuals in teleological systems based purely on instrumental rationality and bureaucratic control. // door https://plato.stanford.edu/entries/weber/ // ref chapter 2.2

weber three types of authority : sociological classification of legitimate rule - traditional rooted in custom, charismatic in heroic devotion, rational-legal in enacted rules. // door https://plato.stanford.edu/entries/weber/ // ref chapter 2.3

historical materialism = karl marx methodological framework asserting material relations of production form economic base determining legal and cultural superstructure. // door https://plato.stanford.edu/entries/marx/ // ref chapter 3.1

marxian alienation = condition in capitalist production where worker loses autonomy over labor process, product, fellow workers, and human species essence. // door https://plato.stanford.edu/entries/marx/ // ref chapter 3.2

cultural capital = pierre bourdieu concept encompassing non-financial institutional assets like linguistic competence, credentials, and aesthetic tastes. // door https://plato.stanford.edu/entries/bourdieu/ // ref chapter 4.1

bourdieu habitus = system of internalized embodied dispositions, schemes of perception, and habits structuring practices without conscious coordination. // door https://plato.stanford.edu/entries/bourdieu/ // ref chapter 4.2

dramaturgical analysis = erving goffman sociological perspective modeling human interaction as theatrical performance divided between front stage and back stage. // door https://plato.stanford.edu/entries/goffman/ // ref chapter 5.1

qualitative methods : Semi-structured in-depth interviews, archival analysis, and field ethnography. individualistic reductionism : Explaining systemic social phenomena purely through personal morality or character traits while ignoring institutional incentives and structural barriers. // door https://en.wikipedia.org/wiki/Franz_Boas // ref 11.1 pervasive analytical traps

# trades — link index

Official **doors** into primary skilled trades standards, building codes, machining references, and manufacturing authorities.
When a feeds-and-speeds formula, thread pitch, electrical ampacity table, plumbing venting rule, structural timber span, or welding procedure specification (WPS) is load-bearing, consult the authoritative standard and cite the official door.

| domain / body | trade authority & scope | official door |
|---|---|---|
| **Industrial Press (*Machinery's Handbook*)** | The Bible of mechanical manufacturing: feeds/speeds, threads, fits, tooling | https://industrialpress.com/machinerys-handbook/ |
| **Occupational Safety and Health Admin (OSHA)**| US workplace safety: 29 CFR 1910 (General Industry), 29 CFR 1926 (Construction)| https://www.osha.gov/ |
| **National Fire Protection Association (NFPA)**| NFPA 70: National Electrical Code (NEC) wiring standards & ampacity | https://www.nfpa.org/ |
| **International Association of Plumbing Officials (IAPMO)**| Uniform Plumbing Code (UPC) and Uniform Mechanical Code (UMC) | https://www.iapmo.org/ |
| **International Code Council (ICC)** | International Residential Code (IRC) & International Building Code (IBC) | https://www.iccsafe.org/ |
| **American Welding Society (AWS)** | Structural Welding Code (AWS D1.1), electrode classifications, inspection | https://www.aws.org/ |
| **NIST Manufacturing Engineering** | Dimensional metrology, machine tool accuracy standards, calibration | https://www.nist.gov/programs-projects/manufacturing |
| **American Wood Council (AWC)** | National Design Specification (NDS) for Wood Construction, joist spans | https://awc.org/ |

## Usage of Primary Doors
1. Identify the trade discipline (machining/metrology, electrical, plumbing/hydronics, carpentry/framing, welding/metallurgy).
2. For statutory work, verify against the currently adopted jurisdiction code (e.g. NEC 2023 or 2026, IRC 2024).
3. For machining feeds and speeds, use *Machinery's Handbook* or manufacturer tooling catalog chip load data.

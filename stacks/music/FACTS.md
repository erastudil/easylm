standard musical concert pitch : international standard ISO 16 defining reference pitch A4 above middle C at fundamental frequency of exactly 440 Hertz. // door https://www.iso.org/standard/3601.html // ref chapter 1.1

harmonic overtone series : sequence of pure sinusoidal frequencies integer multiples of fundamental frequency f - octave 2f, fifth 3f, fourth 4f, major third 5f. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 2.1

pythagorean comma : acoustic discrepancy of approximately 23.46 cents between twelve pure musical fifths and seven pure musical octaves. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 4.1

twelve tone equal temperament = tuning system dividing musical octave into twelve semitones each having identical frequency ratio of twelfth root of two, approximately 1.059463. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 4.2

major diatonic scale formula : seven note step sequence comprised of whole step, whole step, half step, whole step, whole step, whole step, half step. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 5.1

circle of fifths = geometric clockwise representation of chromatic twelve tones where adjacent keys are separated by interval of a perfect fifth. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 5.2

authentic musical cadence = harmonic progression moving from dominant fifth V chord to tonic root I chord creating strong musical resolution. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 6.1

species counterpoint parallel motion prohibition : voice leading rule formulated by johann joseph fux strictly prohibiting parallel motion between two voices by perfect fifths or perfect octaves. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 7.1

sonata allegro form = classical musical architecture consisting of thematic exposition, harmonically unstable development section, and tonic recapitulation. // door https://ocw.mit.edu/courses/music-and-theater-arts/ // ref chapter 8.1

motion types : Contrary motion voices move in opposite directions is preferred over similar or parallel motion because it maximally preserves the acoustic independence of the voices. // door https://viva.pressbooks.pub/openmusictheory/ // ref core voice-leading rules

prohibition of parallel fifths and octaves : Two voices may never move from one perfect fifth to another perfect fifth, or from one perfect octave to another octave, by parallel motion. the circle of fifths : A clockwise geometric progression by perfect fifths adding sharps F^\sharp, C^\sharp, G^\sharp, D^\sharp, A^\sharp, E^\sharp, B^\sharp, or counter-clockwise by fourths adding flats B^\flat, E^\flat, A^\flat, D^\flat, G^\flat, C^\flat, F^\flat. // door https://viva.pressbooks.pub/openmusictheory/ // ref 10.1 sonata-allegro form

# Chapter 0. A thing you can measure, then wait

Drop a stone. It was here. A moment later it is lower. You can count the wait. You can count the drop. Physics is the craft of predicting the next measurement from the last ones, with a rule that still works when you change the stone, the town, and the day.

The rule will be a sentence with letters: mass, time, a push, a distance. Those letters are the algebra pack's bags, with units from numeracy. $F = ma$ says the push is the mass times how quickly the speed is changing. You can check it with a scale, a clock, and a known mass. NIST and BIPM own the units. Fetch them when a number must travel.

This file later names Lagrangians, Maxwell, entropy, spacetime, and a wave in a box. Those are the same craft in harder clothes: a state you can write down, a rule for the next moment, a quantity that does not change.

If the stone's path as a graph of height versus time is new, stay here. Slope of that graph is how fast the height is changing. That slope is the speed. Calculus is the name for slope of a curve. You may learn the name in the math pack after you can see the stone.

## Usage of Primary Doors
1. Identify the physical subdiscipline (geological, atmospheric, marine, hydrological).
2. Query the official agency door using standard scientific coordinates (WGS84, UTC timestamp, isobaric level).
3. If reporting observational data (e.g. atmospheric CO₂ ppm from Mauna Loa or earthquake focal mechanism), cite the official station record.

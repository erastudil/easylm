# Chapter 0. A rule you can check

"Adding in either order gives the same pile." Try it on 7 and 5, and on 100 and 1. You cannot try it on every pair. So you either keep testing, or you write why it must hold from the way addition was defined.

This library's mathematics is that craft: a rule said so clearly that another person can try to break it, and only the rules that do not break are kept.

That jump, from many examples to a reason that covers the ones you did not try, is **proof**. The rest of this book is kinds of rules, and kinds of reasons.

If a letter for an unknown number still feels like a code, open the algebra pack, then return. If 0.25 and 25% are not yet the same share, open numeracy.

A map of groups, rings, limits, and contour integrals is hanging later in this file. It is a catalog of rooms. You do not need the catalog to enter the first room. The first room is a sentence that is either true or false, and a second sentence that must follow if the first is true.

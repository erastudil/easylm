## how to use a door

1. name the question in one sentence.
2. search with the query in the table.
3. open the **official** host (git-scm, GitHub Docs, IETF, sqlite.org, python.org, MDN, language books), not a blog recap.
4. fetch the page if you will cite a method, a status code, a grammar production, or a limit.
5. if two official pages disagree, say so. do not average them.

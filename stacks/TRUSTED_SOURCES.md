# trusted sources

The Stacks cites **hosts that own the fact**. pack `LINK_INDEX.md` files list the doors. this file is the class list.

## classes

| class | use for | examples |
|---|---|---|
| metrology & constants | numbers that must not drift | NIST, BIPM, CODATA |
| open textbooks | undergrad walkthroughs | OpenStax, MIT OCW |
| standards | protocols, encodings, units | IETF RFC, W3C, WHATWG, ECMA, Unicode, IEEE, ISO catalog |
| language & platform docs | APIs we name | docs.python.org, MDN, Rust book, TC39, Kotlin |
| government primary | statute, court, stats, weather, health | Congress, courts, census, NWS, CDC, NIH, NASA |
| journals / preprints | research claims | DOI on the publisher, arXiv as preprint not gospel |
| encyclopedic seed | orientation only | Wikipedia / Wikiquote / Wikisource via EasyLM fetch |

## refuse as source of truth

homework-help mills, Quizlet dumps, Chegg / CourseHero / Brainly, uncited blogs, social proof of a conjecture, a model’s memory of a constant, a scraped formula table with no host.

## course items

Studio quizzes and exams use **authored keys**. OpenStax CC BY may be adapted with attribution in the pack license line. MIT OCW, PhET, LibreTexts are **doors** — link, do not vendor NC bodies into git. Empty item bank = stub = do not ship.

Wikipedia orients. it does not beat NIST on a constant, IETF on a protocol, or a legislature on a statute.

# Chapter 0. Try it, then try to break it

You think a thing is true. The honest next move is to look for a way it would fail.

A plant in the window grows. You think the window is why. Move a twin plant to a dark shelf and keep the water the same. If both grow, the window was not the why. If only the window plant grows, the window still might be light, or warmth, or both. Change one thing at a time when you can.

That habit is the scientific method, before the names. A guess you could be wrong about is a **hypothesis**. A try that could show you wrong is a **test**. A number from the try is data. Data without a denominator is a story; the data pack is the prior book.

This file later names Popper, p-values, Bayes, and causal graphs. Those are tools for the same habit when the world is noisy and people want to fool themselves. If a chapter uses a percent or a sample, and you cannot name the whole, go back to data. If you cannot keep an object on paper, go back to study.

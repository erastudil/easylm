# FACTS — Scientific Method & Inquiry (001)
# Canonical Progen dialect facts grounded in TEXTBOOK.md and LINK_INDEX.md.

scientific method = empirical inquiry via hypothesis generation, systematic observation, reproducible experimentation, and falsification. // door https://plato.stanford.edu/entries/scientific-method/ // ref chapter 1.1

karl popper falsification : a hypothesis is scientific only if it makes precise empirical predictions capable of being proven false. // door https://plato.stanford.edu/entries/popper/ // ref chapter 1.1

problem of induction : david hume philosophical finding that empirical observation of particulars cannot deductively prove universal generalizations. // door https://plato.stanford.edu/entries/induction-problem/ // ref chapter 1.1

kuhnian paradigm shift : revolutionary transition where accumulated empirical anomalies force scientific community to replace foundational model. // door https://plato.stanford.edu/entries/thomas-kuhn/ // ref chapter 1.2

normal science = scientific puzzle solving conducted within an accepted paradigm without questioning underlying foundations. // door https://plato.stanford.edu/entries/thomas-kuhn/ // ref chapter 1.2

operationalization = process of translating an abstract theoretical concept into an empirical, measurable, and reproducible metric. // door https://plato.stanford.edu/entries/scientific-method/ // ref chapter 2.1

null hypothesis = default statistical baseline asserting no true effect, relationship, or difference exists between tested populations. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.2

alternative hypothesis = experimental proposition asserting a genuine effect, difference, or relationship exists. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.2

type I error = false positive decision error rejecting null hypothesis when null hypothesis is actually true. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.3

type II error = false negative decision error failing to reject null hypothesis when alternative hypothesis is true. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.3

alpha significance level = maximum acceptable probability of committing type I error conventionally set to 0.05 or 0.01. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.3

statistical power = probability of correctly rejecting false null hypothesis calculated as 1 minus beta. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 2.3

randomized controlled trial = experimental study design allocating participants randomly between treatment and control groups to eliminate confounding. // door https://training.cochrane.org/handbook // ref chapter 3.1

placebo effect = measured psychological or physiological improvement resulting from inert intervention due to subject expectation. // door https://training.cochrane.org/handbook // ref chapter 3.2

double blind protocol = experimental control where neither participants nor researchers know treatment allocation until trial conclusion. // door https://training.cochrane.org/handbook // ref chapter 3.2

quasi experiment = empirical study estimating causal impact of intervention without random assignment of subjects to conditions. // door https://ocw.mit.edu/courses/economics/ // ref chapter 3.3

guide to expression of uncertainty : international JCGM metrology standard establishing unified mathematical framework for evaluating measurement uncertainty. // door https://www.bipm.org/en/committees/jc/jcgm/publications // ref chapter 4.1

systematic error = predictable and reproducible directional measurement offset caused by flawed equipment calibration or environmental bias. // door https://www.bipm.org/en/committees/jc/jcgm/publications // ref chapter 4.2

random error = unpredictable stochastic measurement variation arising from unpredictable temporal and spatial fluctuations. // door https://www.bipm.org/en/committees/jc/jcgm/publications // ref chapter 4.2

uncertainty propagation formula : variance of function f of independent variables equals sum of squared partial derivatives times individual variances. // door https://www.bipm.org/en/committees/jc/jcgm/publications // ref chapter 4.3

p value = probability of obtaining test results at least as extreme as observed data assuming null hypothesis is true. // door https://www.nature.com/articles/d41586-019-00857-9 // ref chapter 5.1

cohen d = standardized effect size measuring difference between two group means divided by pooled standard deviation. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 5.2

confidence interval = interval estimated from sample data that would contain true population parameter at specified long run frequency. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 5.3

bayes theorem : probability of hypothesis given data equals likelihood of data given hypothesis times prior probability divided by evidence. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 6.1

prior probability = probability distribution assigned to hypothesis before incorporating new empirical evidence. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 6.2

posterior probability = updated probability distribution of hypothesis calculated after applying bayes theorem to new data. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 6.2

credible interval = bayesian interval containing true parameter value with specified subjective posterior probability. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 6.3

causal directed acyclic graph = graphical mathematical model representing causal assumptions via directed edges without feedback loops. // door https://bayes.cs.ucla.edu/jp_home.html // ref chapter 7.1

confounder variable = common cause influencing both independent exposure variable and dependent outcome variable creating spurious correlation. // door https://bayes.cs.ucla.edu/jp_home.html // ref chapter 7.2

collider variable = variable causally influenced by two distinct parent variables whose conditioning induces spurious association between parents. // door https://bayes.cs.ucla.edu/jp_home.html // ref chapter 7.2

back door criterion : graphical condition identifying whether conditioning on set of covariates blocks all spurious non-causal paths. // door https://bayes.cs.ucla.edu/jp_home.html // ref chapter 7.3

simpson paradox = statistical phenomenon wherein statistical trend observed in aggregate data reverses when partitioned into subgroups. // door https://bayes.cs.ucla.edu/jp_home.html // ref chapter 7.4

bradford hill criteria : nine epidemiological guidelines assessing causality - strength, consistency, specificity, temporality, gradient, plausibility, coherence, experiment, analogy. // door https://www.ncbi.nlm.nih.gov/pmc/articles/PMC1898525/ // ref chapter 7.5

stratified sampling = probability sampling method dividing population into homogeneous subpopulations before drawing independent random samples. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 8.1

selection bias = systematic distortion resulting from non-random participant recruitment leading to unrepresentative sample. // door https://training.cochrane.org/handbook // ref chapter 8.2

survivorship bias = logical error focusing exclusively on entities passing selection process while overlooking failures that fell silent. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 8.3

replication crisis = methodological crisis in behavioral and biomedical science where independent teams fail to replicate landmark published findings. // door https://journals.plos.org/plosmedicine/article?id=10.1371/journal.pmed.0020124 // ref chapter 9.1

p hacking = data dredging practice manipulating model variables, subsets, and covariates until p-value drops below significance threshold. // door https://osf.io/ // ref chapter 9.2

harking = hypothesizing after results are known presenting post hoc exploratory findings as a priori confirmatory hypotheses. // door https://osf.io/ // ref chapter 9.2

study preregistration = public timestamped archiving of experimental design, hypotheses, and analytical pipeline prior to data collection. // door https://osf.io/ // ref chapter 9.3

systematic review = comprehensive literature synthesis identifying, appraising, and synthesizing all empirical evidence against explicit eligibility criteria. // door http://www.prisma-statement.org/ // ref chapter 10.1

meta analysis = statistical integration combining quantitative effect estimates across independent empirical studies into single pooled effect size. // door https://training.cochrane.org/handbook // ref chapter 10.2

forest plot = graphical representation displaying effect size estimates and confidence intervals for individual studies alongside pooled summary. // door https://training.cochrane.org/handbook // ref chapter 10.3

publication bias = systematic distortion where positive statistically significant findings are published more readily than null or negative results. // door https://training.cochrane.org/handbook // ref chapter 10.4

funnel plot = scatter plot of study effect size against sample precision used to visually detect publication bias via asymmetry. // door https://training.cochrane.org/handbook // ref chapter 10.4

cargo cult science = research mimicking outward formalities and apparatus of science while lacking integrity to thoroughly test contradictory explanations. // door https://calteches.library.caltech.edu/51/2/CargoCult.htm // ref chapter 11.1

goodhart law : when a measure becomes a target, it ceases to be a good measure. // door https://ocw.mit.edu/courses/economics/ // ref chapter 11.2

ecological fallacy = logical error inferring individual level relationships directly from aggregated group level statistics. // door https://ocw.mit.edu/courses/mathematics/ // ref chapter 11.3

the problem of induction : No matter how many thousands of white swans you observe, you can never prove the universal claim that "all swans are white," because observing a single black swan in Australia shatters the generalization instantly. Induction cannot logically establish universal empirical laws. // door https://www.itl.nist.gov/div898/handbook/ // ref 1.1 the demarcation problem & falsificationism karl popper

popper's falsification criterion : A theory is scientific if and only if it makes precise, risky empirical predictions that could be demonstrated false by an observable experiment. // door https://www.itl.nist.gov/div898/handbook/ // ref 1.1 the demarcation problem & falsificationism karl popper

anomalies and crisis : Over time, stubborn empirical anomalies emerge that cannot be shoehorned into the reigning framework. When anomalies multiply, the discipline enters an institutional crisis. // door https://www.itl.nist.gov/div898/handbook/ // ref 1.2 paradigm shifts & scientific revolutions thomas kuhn

paradigm shift : A new paradigm emerges e.g. from Ptolemaic epicycles to Copernican heliocentrism; from Newtonian absolute space to Einsteinian relativistic spacetime that reinterprets existing evidence and opens a new era of inquiry. // door https://www.itl.nist.gov/div898/handbook/ // ref 1.2 paradigm shifts & scientific revolutions thomas kuhn

random assignment : Participants are allocated to treatment and control groups by a random mechanism such as a pseudo-random number generator. Randomization ensures that all confounding variables—both observed age, sex and unobserved genetics, childhood diet, motivation—are distributed evenly between cohorts. // door https://www.itl.nist.gov/div898/handbook/ // ref 3.1 the randomized controlled trial rct

placebo controls : Ensures that improvements caused by psychological expectations, patient optimism, or the rituals of care are accounted for. // door https://www.itl.nist.gov/div898/handbook/ // ref 3.1 the randomized controlled trial rct

factorial designs : Simultaneously manipulates two independent variables, enabling researchers to detect interaction effects where the effect of one factor depends on the presence of another. // door https://www.itl.nist.gov/div898/handbook/ // ref 3.2 factorial & quasi-experimental designs

natural & quasi-experiments : When randomized intervention is unethical or physically impossible e.g. evaluating the health impact of cigarette smoking or an earthquake, researchers use quasi-experimental techniques - difference-in-differences, regression discontinuity, and instrumental variables. // door https://www.itl.nist.gov/div898/handbook/ // ref 3.2 factorial & quasi-experimental designs

construct validity : Whether the test measures the actual theoretical entity it claims to measure. // door https://www.itl.nist.gov/div898/handbook/ // ref 4.1 precision, accuracy, and validity

cohen's $d$ : The difference between two group means divided by their pooled standard deviation - . // door https://www.itl.nist.gov/div898/handbook/ // ref 5.2 effect size metrics

pearson's $r$ and $r^2$ : Quantifies the proportion of variance shared between variables R^2 = 0.25 means 25% of the variance is explained. // door https://www.itl.nist.gov/div898/handbook/ // ref 5.2 effect size metrics

simple random sampling : Every member of the target population has an equal probability of selection. // door https://www.itl.nist.gov/div898/handbook/ // ref 8.1 sampling techniques

stratified random sampling : The population is divided into mutually exclusive strata e.g. age, geography, income, and samples are drawn proportionally from each stratum to ensure accurate subgroup representation. // door https://www.itl.nist.gov/div898/handbook/ // ref 8.1 sampling techniques

non-response bias : When individuals who decline to participate hold systematically different attitudes from those who respond. // door https://www.itl.nist.gov/div898/handbook/ // ref 8.2 systematic sampling biases

the file-drawer problem : Academic journals historically preferred novel, positive findings, consigning negative replication failures to researchers' filing cabinets. // door https://www.itl.nist.gov/div898/handbook/ // ref 9.1 questionable research practices qrps

study pre-registration : Publicly time-stamping hypotheses, sampling plans, and exact statistical code on platforms like OSF before data collection begins. // door https://www.itl.nist.gov/div898/handbook/ // ref 9.2 the open science revolution

registered reports : Journals grant in-principle acceptance prior to data collection based purely on methodological rigor and theoretical importance, guaranteeing publication regardless of whether results are positive or negative. // door https://www.itl.nist.gov/div898/handbook/ // ref 9.2 the open science revolution

open data & open code : Making raw data tables and execution scripts publicly verifiable and reproducible by independent auditors. // door https://openstax.org/details/books/introductory-statistics-2e // ref 9.2 the open science revolution

narrative review : An author hand-picks favorite studies to support a predetermined thesis high susceptibility to confirmation bias. // door https://www.itl.nist.gov/div898/handbook/ // ref 10.1 systematic reviews vs narrative reviews

forest plots : Graphically displays effect sizes and 95% confidence intervals from every included study, alongside a summary diamond representing the weighted pooled effect. // door https://www.itl.nist.gov/div898/handbook/ // ref 10.2 meta-analytic tools

funnel plots : Plots effect size against sample size / standard error. In the absence of publication bias, the plot resembles a symmetric inverted funnel. Asymmetry missing studies in the bottom-left region of small, non-significant findings reveals the telltale signature of publication bias. // door https://www.itl.nist.gov/div898/handbook/ // ref 10.2 meta-analytic tools

leaning over backwards : Feynman's mandate - you must actively seek out and document every fact, alternative explanation, or possible experimental glitch that could prove your favorite hypothesis wrong. // door https://www.itl.nist.gov/div898/handbook/ // ref 11.1 the core scientific virtues

double-checking the negative control : If your assay or instrument yields a positive signal when exposed to plain distilled water, your experimental readings on actual samples are worthless. // door https://www.itl.nist.gov/div898/handbook/ // ref 11.1 the core scientific virtues

distinguishing prediction from post-hoc storytelling : Fitting a polynomial curve to 100 historical data points is easy; predicting the 101st point in advance is the real test of a scientific model. // door https://www.itl.nist.gov/div898/handbook/ // ref 11.1 the core scientific virtues

transparent failure reporting : Reporting when an experiment failed to produce an effect is just as valuable to humanity as reporting when it succeeded. It saves other researchers millions of dollars and years of wasted effort. // door https://www.itl.nist.gov/div898/handbook/ // ref 11.1 the core scientific virtues

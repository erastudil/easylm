# Canonical Progen dialect facts grounded in TEXTBOOK.md and LINK_INDEX.md.

poetic meter = structured rhythmic temporal recurrence of accented and unaccented syllabic beats organizing verse lines. // door https://www.poetryfoundation.org/learn/glossary-terms/meter // ref chapter 1.1

iambic metric foot = two-syllable poetic foot composed of an unstressed short syllable followed by a stressed long syllable. // door https://www.poetryfoundation.org/learn/glossary-terms/iamb // ref chapter 3.1

trochaic metric foot = two-syllable poetic foot composed of a stressed long syllable followed by an unstressed short syllable. // door https://www.poetryfoundation.org/learn/glossary-terms/trochee // ref chapter 3.1

anapestic metric foot = three-syllable poetic foot composed of two unstressed syllables followed by one stressed syllable. // door https://www.poetryfoundation.org/learn/glossary-terms/anapest // ref chapter 3.1

dactylic metric foot = three-syllable poetic foot composed of one stressed syllable followed by two unstressed syllables. // door https://www.poetryfoundation.org/learn/glossary-terms/dactyl // ref chapter 3.1

spondaic metric foot = two-syllable poetic foot composed of two equally stressed long syllables producing heavy metrical accent. // door https://www.poetryfoundation.org/learn/glossary-terms/spondee // ref chapter 3.1

iambic pentameter line = verse line composed of five consecutive iambic feet comprising ten syllables with alternating unstressed and stressed pattern. // door https://www.poetryfoundation.org/learn/glossary-terms/iambic-pentameter // ref chapter 3.2

blank verse = unrhymed metric verse composed in regular iambic pentameter widely favored in classical english dramatic and epic poetry. // door https://www.poetryfoundation.org/learn/glossary-terms/blank-verse // ref chapter 3.3

free verse cadence = poetic form dispensing with regular meter and rhyme schemes, organized instead around natural speech cadence and typographic lineation. // door https://www.poetryfoundation.org/learn/glossary-terms/free-verse // ref chapter 10.1

poetic enjambment = syntactic continuation of sentence across line break without terminating punctuation pause. // door https://www.poetryfoundation.org/learn/glossary-terms/enjambment // ref chapter 5.1

poetic caesura = audible metric pause or rhythmic fracture occurring within interior of a poetic verse line. // door https://www.poetryfoundation.org/learn/glossary-terms/caesura // ref chapter 5.2

petrarchan sonnet structure : fourteen line verse form composed of an initial eight line octave establishing problem followed by a volta turn and six line sestet. // door https://www.poetryfoundation.org/learn/glossary-terms/sonnet-petrarchan // ref chapter 8.1

shakespearean sonnet structure : fourteen line verse form composed of three rhyming quatrains abab cdcd efef concluding with a rhyming heroic couplet gg. // door https://www.poetryfoundation.org/learn/glossary-terms/sonnet-shakespearean // ref chapter 8.2

villanelle closed form = nineteen line poetic form consisting of five tercets and concluding quatrain structured around two repeating refrains and two rhyme sounds. // door https://www.poetryfoundation.org/learn/glossary-terms/villanelle // ref chapter 8.3

classical haiku form : traditional japanese poetic form consisting of seventeen morae in 5-7-5 metric measure containing seasonal kigo and cutting word kireji. // door https://www.poetryfoundation.org/learn/glossary-terms/haiku // ref chapter 9.1

terza rima stanza scheme : interlocking three-line rhyme scheme aba bcb cdc invented by dante alighieri for the divine comedy. // door https://www.poetryfoundation.org/learn/glossary-terms/terza-rima // ref chapter 5.3

spenserian stanza architecture : nine-line verse form rhyming ababbcbcc with eight iambic pentameter lines and concluding twelve-syllable iambic hexameter alexandrine. // door https://www.poetryfoundation.org/learn/glossary-terms/spenserian-stanza // ref chapter 5.4

ottava rima structure : eight-line iambic pentameter stanza rhyming abababcc utilized in narrative epic verse by boccaccio, ariosto, and lord byron. // door https://www.poetryfoundation.org/learn/glossary-terms/ottava-rima // ref chapter 5.5

ballad meter stanza : traditional four-line quatrain alternating four-stress iambic tetrameter and three-stress iambic trimeter rhyming abcb or abab. // door https://www.poetryfoundation.org/learn/glossary-terms/ballad-meter // ref chapter 11.1

sestina closed form : thirty-nine line poetic form consisting of six six-line stanzas and a three-line envoi repeating six terminal teleuton words in rotating sequence. // door https://www.poetryfoundation.org/learn/glossary-terms/sestina // ref chapter 8.4

the beat : In spoken English, some syllables are loud and long while others are soft and quick. When those pulses arrange into predictable patterns, your ear catches the beat naturally, like tapping your foot to music. // door https://www.poetryfoundation.org/learn/glossary-terms // ref table of contents

the turn : Where a line breaks creates a micro-pause. That pause gives extra weight to the last word on the line and the first word of the next. If the sentence continues across the break without pausing, that tension is called enjambment. // door https://www.poetryfoundation.org/learn/glossary-terms // ref table of contents

the image : Instead of explaining an emotion with abstract labels "I was sad", poetry anchors feeling in concrete sensory objects you can see, hear, or touch—a cold radiator, a rusted nail, the smell of wet pavement after rain. // door https://www.poetryfoundation.org/learn/glossary-terms // ref table of contents
